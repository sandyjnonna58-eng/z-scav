# Z-SCAV

Геймод-мод для Garry's Mod на основе Remorseism (форк Z-City / Homigrad).

## Состав
- `z-scav/` — **полная версия**: код + весь контент. Этого достаточно, чтобы играть.
- `z-scav-content/` — **только контент** (картинки, звуки, шрифты) отдельным аддоном, например для Workshop-контент-пака.

## Установка
Скопировать папку `z-scav` в `garrysmod/addons`. Папку `z-scav-content` ставить не нужно, если стоит полная версия.

## Основное
- главное меню-лагерь, ночная тема
- меню здоровья SCAV-HEALTH (N): кукла, части тела, ЭКГ, медицина только через меню
- настроение, депрессия, апатия, психоз, последний бой
- голод, жажда, переедание, кожа, инфекция, сепсис, иммунитет, грязь, глухота
- энергия и сон (кнопка «СОН» в меню здоровья)
- мини-игры: бинт, шприц, СЛР, извлечение осколков
- музыка состояний: Dying, Death, Despair, Drowning, Exhausted, Is this the end, PainDrone, Last stand, Fury-13
