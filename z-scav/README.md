# Z-SCAV

Гейммод для Garry's Mod.

Основан на Remorseism (github.com/kazoo43/remorseism), который в свою очередь основан на Z-City (github.com/uzelezz123/Z-City).
Лицензия: GNU AGPL v3 (см. LICENSE).

## Установка

Это ПОЛНАЯ сборка: код, гейммод, картинки, звуки, музыка и шрифты - всё в одной папке.
Положите папку `z-scav` в `garrysmod/addons/`.
